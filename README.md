# 🛒 E-Commerce RAJAGROUP

E-Commerce **RAJAGROUP** adalah aplikasi web e-commerce yang digunakan untuk mengelola produk, transaksi, dan pengguna dalam satu sistem terintegrasi.

Project ini dibuat sebagai implementasi sistem e-commerce berbasis web dan digunakan untuk kebutuhan pembelajaran, pengembangan skill, serta dokumentasi project pribadi.

---

## 🛠 Teknologi yang Digunakan

- **Bahasa Pemrograman**: PHP
- **Database**: MySQL
- **Frontend**: HTML, CSS, JavaScript
- **Framework / Library UI**: Bootstrap
- **Server**: Apache (XAMPP / Laragon)
- **Tools**:
  - Visual Studio Code
  - phpMyAdmin
  - Git & GitHub

---

## ✨ Fitur Utama

- Manajemen produk (tambah, ubah, hapus)
- Manajemen kategori produk
- Sistem transaksi / pemesanan
- Manajemen pengguna
- Halaman admin
- Koneksi database MySQL

---

## 🎯 Tujuan Project

- Menerapkan konsep e-commerce berbasis web
- Melatih pengelolaan database & transaksi
- Memahami alur aplikasi e-commerce (admin & user)
- Menyimpan dokumentasi project sebagai arsip dan portfolio
